# NEXORA PAY

NEXORA PAY is a production-oriented fintech platform starter with a strong dark fintech identity and clean architecture.

## Stack

- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: NestJS, TypeScript
- Database: PostgreSQL
- Cache: Redis
- Infra: Docker

## Local environment

```bash
docker compose up -d
npm install
npm run dev
```

Then open:
- Frontend: http://localhost:3000
- Backend: http://localhost:4000/api

## Modules

- NEXORA PAY
- NEXORA WALLET
- NEXORA BUSINESS
- NEXORA ADMIN
- NEXORA SECURITY
- NEXORA API

## Important

This project is a serious fintech architecture and starter implementation. It does not create Pix approval or money movement by itself. Real bank/Pix transactions require an authorized financial provider, production credentials, and compliant deployment.
